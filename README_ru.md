# AI Launcher Studio

[English](README.md)

**AI Launcher Studio** — десктопное приложение для Windows, которое помогает запустить нейросеть в пару кликов: локально на своём ПК или онлайн через провайдера. Сделано так, чтобы было понятно новичку и при этом давало полный контроль профи.

Технологии: .NET 8, Avalonia UI 12.

## Что умеет

- **Локальная нейросеть** — запускает `llama-server` с вашей GGUF-моделью и общается с ней во встроенном чате. Работает на CPU и на видеокартах Intel/AMD (Vulkan), а не только на NVIDIA.
- **Онлайн нейросеть** — встроенный чат к OpenAI, OpenRouter, Anthropic (Claude) или своему адресу. Поддержка прокси Hiddify для заблокированных провайдеров.
- **Диаграмма памяти** — наглядно показывает, как модель ложится в память одной/двух видеокарт и системную RAM, и предупреждает, если не помещается.
- **Проверка конфликтов настроек** — объясняет простым языком, если настройки несовместимы (например, MTP без подходящей модели, TurboQuant без нужной сборки, контекст больше нативного) и как это исправить.
- **Подсказки у каждого параметра** — иконка «?» с понятным объяснением «что это / зачем / на что влияет».
- **Модели** — локальный каталог GGUF и поиск на Hugging Face с подсветкой динамических квантов (UD-Q4_K_XL и т.п.).
- **Среды (runtime)** — рекомендует движок под ваше железо и реально скачивает и устанавливает сборку llama.cpp с GitHub.
- **Агенты** — запуск кодинг-агентов (OpenCode, Kilo, Claw, Aider) на локальной или онлайн модели.

## Запуск из исходников

```powershell
dotnet run --project src\Launcher.Desktop\Launcher.Desktop.csproj
```

## Сборка и тесты

```powershell
dotnet restore .\AI-Launcher-Studio.sln
dotnet build .\AI-Launcher-Studio.sln --no-restore
dotnet test .\AI-Launcher-Studio.sln --no-build
```

## Быстрый старт для новичка

1. Откройте вкладку **Среды (runtime)** → «Найти сборки» → «Скачать и установить» рекомендованную (для Intel/AMD это Vulkan).
2. Откройте вкладку **Модели** → найдите модель на Hugging Face или укажите папку с уже скачанными `.gguf`.
3. Откройте вкладку **Чат** → раздел «Локальный сервер» → укажите модель → «Запустить». Когда статус станет «готов», пишите сообщения.

Либо сразу **Чат** → выберите онлайн-провайдера, введите API-ключ и общайтесь.

## Архитектура

```text
src\Launcher.Core      сценарии, профили, настройки, decoding-пресеты, подсказки параметров
src\Launcher.Runtimes  llama.cpp runtime, порты, процессы, железо/VRAM, движок конфликтов, диаграмма памяти
src\Launcher.Models    локальный каталог GGUF и поиск/скачивание на Hugging Face
src\Launcher.Agents    запуск и определение кодинг-агентов
src\Launcher.Online    онлайн-провайдеры и стриминговый чат (OpenAI-совместимый и Anthropic)
src\Launcher.Desktop   интерфейс на Avalonia (страницы Главная/Чат/Модели/Агенты/Среды/Настройки)
tests\                 unit-тесты по слоям
```
