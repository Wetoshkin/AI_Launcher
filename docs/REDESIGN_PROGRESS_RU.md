# Прогресс редизайна AI Launcher Studio

Полный редизайн продукта: понятный новичку и мощный для профи лаунчер локальных и онлайн нейросетей. Спецификация — `docs/superpowers/specs/2026-06-12-ai-launcher-studio-redesign-design.md`.

## Готово

### Этап 1 — фундамент Desktop-шелла
- Новый multi-view интерфейс на Avalonia 12 (`ShellViewModel` + страницы Главная/Чат/Модели/Среды/Настройки) вместо старого god-объекта.
- Тёплая «бумажная» тема, боковая навигация с подсветкой активного пункта.
- DPI-корректная вёрстка (проверено на 150%): окно не обрезается, шрифты адекватные.

### Этап 2 — определение железа и диаграмма памяти
- `WmiHardwareProbe`: определяет CPU, видеокарты (Intel/AMD/NVIDIA, в т.ч. встроенные) и объём RAM. Работает без NVIDIA.
- `DeviceMemoryPlanner`: рассчитывает, как модель (веса + KV-кэш + overhead) ложится по видеокартам и системной RAM.
- `HardwareMemoryView`: наглядная диаграмма загрузки памяти одной/двух карт + RAM, с вердиктом «помещается / не помещается».
- Главная показывает реальное железо и пример раскладки.

### Этап 3 — конфликты настроек и подсказки
- `SettingsConflictEngine`: проверяет реальные конфликты (MTP ↔ модель/runtime, TurboQuant ↔ runtime, контекст ↔ нативный, CUDA ↔ не-NVIDIA, нехватка памяти) и объясняет простым языком с готовым исправлением.
- `ParameterHelpCatalog`: понятная подсказка по каждому параметру (что/зачем/на что влияет) — иконка «?» у любого поля.
- Контролы `HelpHint` и `ConflictPanel`.

### Этап 4 — дашборд-хаб и встроенный чат
- Главная стала хабом: крупные кнопки «Локальная нейросеть» / «Онлайн нейросеть» + Модели/Среды.
- Встроенный чат со стримингом ответов (пузыри), отменой, обработкой ошибок. Проверено вживую.

### Этап 5 — онлайн-провайдеры
- Провайдеры OpenAI / OpenRouter / Anthropic / локальный / свой адрес.
- Anthropic-клиент (Messages API) и OpenAI-совместимый клиент, выбор автоматически.
- Прокси Hiddify для онлайна (локальные адреса в обход). Выбор провайдера и прокси в чате.

### Этап 7 — экраны Модели и Среды
- Модели: локальный каталог GGUF (выбор папки + скан + фильтр) и живой поиск на Hugging Face с подсветкой динамических квантов.
- Среды: рекомендация движка по железу (Intel/AMD → Vulkan, NVIDIA → CUDA), список реальных сборок llama.cpp с GitHub, **реальное скачивание и установка** (проверено: Vulkan-сборка скачана, распакована, llama-server.exe найден).

### Этап 4в — реальный локальный запуск
- В чате секция «Локальный сервер»: авто-определение установленного runtime, выбор .gguf, порт.
- Кнопка «Запустить» поднимает настоящий llama-server, ждёт готовности `/v1/models`, чат сам подключается.
- **Проверено вживую сквозь весь путь**: установлен llama-server (Vulkan), запущена локальная модель SmolLM2, она реально ответила в чат.

### Этап 6 — кодинг-агенты
- Страница «Агенты»: проверка установленных CLI (OpenCode/Kilo/Claw/Aider/Pi), выбор проекта, источник модели (локальный сервер или онлайн), запись конфига проекта и запуск.
- Попутно исправлен баг определения CLI (показывал «установлен» для отсутствующих).

### Прочее
