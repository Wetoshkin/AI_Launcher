# Ресёрч 2026: как сделать AI Launcher Studio ультимативным

Сводка критического анализа ~28 источников (GitHub llama.cpp, Habr, дизайн-блоги NN/g, Apple, Avalonia). Используется для приоритизации фич и дизайна.

## 1. Конкуренты (что забрать)

- **LM Studio** — эталон для профи: model browser, **MCP** (инструменты: файлы/веб/код), SDK, MLX. → нам: полировка каталога моделей, в перспективе MCP/инструменты.
- **GPT4All** — **LocalDocs RAG** (чат со своими PDF/доками) без настройки. → нам: RAG со своими документами — сильная фича.
- **Jan** — open-source, гибрид локально+облако. → у нас уже есть (локальный + онлайн чат).
- **Msty** — персоны, автоматизации, агент. → нам: системные промпты/персоны.
- Общий тренд: «без терминала, чат за 10 минут». Мы это закрываем хабом + локальным запуском в один клик.

## 2. Анти-зацикливание (ключевой запрос)

Критично: **наивный repeat-penalty САМ вызывает зацикливание** на некоторых моделях (находка Unsloth/Daniel Han на QwQ-32B). Правильно:
- **DRY sampler** (Don't Repeat Yourself) — штрафует повторяющиеся *последовательности*, а не отдельные токены. Параметры: `--dry-multiplier` (0=выкл, рабочее ~0.8), `--dry-base` 1.75, `--dry-allowed-length` 2, `--dry-penalty-last-n` -1 (весь контекст).
- **XTC** (Exclude Top Choices) — убирает топ-токены, ломает клише/повторы: `--xtc-probability 0.5`.
- **Порядок сэмплеров важен**: рекомендуется `top_k;top_p;min_p;temperature;dry;typ_p;xtc` или связка Min-P→XTC.
→ нам: пресет **«Анти-зацикливание»**: умеренный repeat-penalty (или 1.0) + DRY 0.8 + XTC 0.5 + правильный порядок. Объяснить новичку простыми словами.

## 3. Скорость/качество (лайфхаки)

- **llama.cpp в 2-3× быстрее Ollama** (Habr) → llama.cpp основной runtime.
- **Динамические кванты** UD-Q4_K_XL/UD-Q2_K_XL (Unsloth/Bartowski) > обычного Q4_K_M при том же весе.
- **KV-cache квантование**: q8_0 ≈ −50% памяти KV; FP16 KV ест ~4 ГБ на 32K (Llama 8B), ~16 ГБ на 128K. TurboQuant (`--cache-type-k turbo3 -fa on`, **flash-attn обязателен**) — для очень длинного контекста.
- **`-ngl`** — главный рычаг (слои на GPU). **batch/ubatch** (512/256 для среднего GPU; больше — быстрее prompt processing, но память). `--parallel`/`-b`/`-ub` связаны — осторожно.
- **Flash Attention** включать (auto по умолчанию, но для turbo KV — обязательно on).
- 7-8B модели — sweet spot для 12 ГБ GPU.

## 4. Мульти-GPU (для 3090 24G + 3060 12G)

- `--split-mode` (`-sm`): `layer` (по умолчанию, слои+KV по картам), `row`, `tensor`(EXPERIMENTAL), `none`.
- `--tensor-split` (`-ts`): пропорции по картам, напр. для 24:12 → `2,1` (66%/33%).
- `--main-gpu` (`-mg`): основная карта.
→ нам: при двух картах предлагать tensor-split пропорционально VRAM, показывать per-GPU раскладку в диаграмме (уже поддержано), дать ручной контроль в Эксперт-режиме.

## 5. Тренды локального запуска 2026

- **MoE доминирует** (Qwen3.5/3.6, GLM-5.1 744B, Gemma4, Kimi K2, GPT-OSS). Для MoE — `-ncmoe`/`-cmoe` вместо чистого `-ngl`.
- **Speculative/MTP** (Qwen3-Next native MTP) — ускорение.
- **MCP** стал стандартом доступа к инструментам (вошёл в Linux Foundation).
- **RAG** смещается к длинному контексту, но «чат со своими документами» всё ещё ценен.
- **Vision** в открытых моделях отстаёт; для картинок лучше онлайн-API.

## 6. Дизайн (macOS-вдохновлённый, критически)

Тренд — **Liquid Glass / glassmorphism** (Apple macOS Tahoe/Golden Gate): полупрозрачность, blur, рефракция. НО критика NN/g и практиков:
- Блюр **только выборочно** (боковая панель, плавающие карточки, модалки), не везде — иначе страдает читаемость.
- Блюр 12-16px; контраст текста **≥4.5:1 (WCAG AA)**; в тёмной теме — светлый текст, тёмный тинт (глубокий синий/фиолет ~10%), плёнка ~30% под текстом, тонкая 1px рамка.
- **Avalonia acrylic ненадёжен в published-сборках** (Issue #8579) → обязателен solid **FallbackColor**, чтобы установленное приложение всегда выглядело хорошо.

**Решение для нас:** чистый воздушный дизайн (много whitespace, мягкие скруглённые карточки 14-16px, тонкие тени, крупная аккуратная типографика, увеличенные отступы), **светлая + тёмная темы**, acrylic на боковой панели/окне с надёжным fallback. Не превращать весь UI в матовое стекло.

## Итоговые фичи к внедрению (приоритет)

1. Лог-консоль процесса (полные логи).
2. Тёмная тема + языки RU/EN.
3. macOS-редизайн (воздух, скругления, тени, типографика, acrylic-сайдбар с fallback).
4. Режим Эксперт: полный набор параметров + пресеты сэмплинга (в т.ч. «Анти-зацикливание» DRY+XTC).
5. Мульти-GPU: tensor-split/split-mode, per-GPU диаграмма.
6. Онбординг первого запуска.
7. Проверка обновлений приложения.
8. (Перспектива) RAG со своими документами, MCP/инструменты, персоны/системные промпты.
